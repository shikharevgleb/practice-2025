# Отчёт о разработке сайта для проекта «Вектора города» с использованием  html|css

---

## 1. Введение

В рамках проектной деятельности передо мной стояла задача создать сайт для проекта «Вектора города» — приложение и сайт для изучения достопремечательностей Москвы. По заданию рекомендовалось использовать генератор статических сайтов Hugo.

---

## 2 Далее я решил создавать сайт не используя Hugo, пользуясь html|css

Работал в редакторе VS code и выгружал свои версии на git используя внутренний терминал

---

## 3. Создание структуры страниц (в соответствии с заданием)
Для создания сайта по заданию я создал 5 страниц

```
index.html # Главная страница(аннотация)
about.html # О проекте
journal.html # Журнал
members.html # Участники
resources.html # Ресурсы
```

---

## 4. Наполнение контентом

**Что я написал:**

- **Главная страница** — аннотация проекта, краткое описание идеи.
- **«О проекте»** — подробное описание цели нашего проета.
- **«Участники»** — таблица с ролями и личным вкладом каждого.
- **«Журнал»** — Пример проделанной работы.
- **«Ресурсы»** — ссылки на полезные статьи, чтобы лучше понять тематику сайта и приложения.

---

## 5. Добавление графических материалов

По заданию сайт должен содержать графику и медиа. Я добавил:

- **Логотип нашего сайта**
- **Фотографии примера проделанной работы**

---

## 6. Настройка навигации

Чтобы пользователям было удобно перемещаться по сайту, я решил реализовать header

```
.header {
        width: 100%;
        height: 70px;
        background: linear-gradient(90deg, #00ffb3, #00e0ff);
        display: flex;
        align-items: center;
        justify-content: space-between;
        padding: 0 80px;
    }

    .header a {
        text-decoration: none;
        color: black;
        margin: 0 20px;
        font-size: 20px;
        font-weight: bold;
    }

    <div class="header">
    <div>
        <a href="./index.html">Главная</a>
    </div>

    <div>
        <a href="./about.html">О проекте</a>
        <a href="./journal.html">Журнал</a>
        <a href="./members.html">Участники</a>
        <a href="./resources.html">Ресурсы</a>
    </div>
</div>
```

После этого в шапке сайта появились ссылки на все разделы.

---

## 7. Локальный запуск и проверка

Перед публикацией я запустил:

```
index.html
```

И сделал тест сайта:
- все страницы открываются,
- меню работает,
- картинки отображаются,
- текст выглядит аккуратно.

Ошибок не было, сайт работал корректно.
