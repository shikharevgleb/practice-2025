ВЕКТОР ГОРОДА

Аннотация проекта

Проект "Вектора города" посвящён разработке сайта и мобильного приложения для изучения достопримечательностей Москвы. Идея проекта заключается в том, чтобы пользователи могли в интересной, а так же игровой форме изучать достопримечательности
