# Отчёт о разработке Telegram-бота для проекта «Вектора города» на Python
---

## 1. Введение

В рамках проектной деятельности помимо сайта мне было необходимо разработать вспомогательный инструмент для взаимодействия с пользователями. Я выбрал Telegram-бота, так как это популярный и удобный способ распространения информации. Бот дополняет основной проект «Ветора-города».

---

## 2. Цель разработки

Создать Telegram-бота, который:

- Знакомит пользователей с проектом «Вектора-Города».
- Предоставляет справочную информацию о достопремечательностях Москвы.
- Имеет удобное меню с кнопками.

---

## 3. Инструменты и технологии

| Компонент | Использованное решение |
|-----------|------------------------|
| Язык программирования | Python |
| Библиотека для бота | `python-telegram-bot` |
| Среда разработки | PyCharm |
| Платформа | Telegram |
| Система | Windows 11 |

---

## 4. Подготовка к разработке

### 4.1. Установка библиотеки

В командной строке Windows я выполнил:

```cmd
pip install python-telegram-bot --upgrade
```

### 4.2. Получение токена бота

Я обратился к **BotFather** в Telegram:
- Отправил команду `/newbot`
- Указал имя бота: `Vektora-goroda`

---

## 5. Структура бота

Бот построен по принципу **меню с кнопками**. Пользователь взаимодействует с ботом, нажимая на кнопки, а не вводя команды вручную.

### 6 Главное меню

При запуске бота командой `/start` пользователь видит:

```
Красная площадь ->
Арбат ->
Крмель ->
Москва-Сити ->
Останкинская башня ->
Царицыно ->
Минин и Пожарский ->
```

## 6. Реализованные функции

### 6.1. Обработка команды `/start`

Бот приветствует пользователя и показывает главное меню.

**Код:**
```
async def start(update: Update, context: ContextTypes.DEFAULT_TYPE):
    await update.message.reply_text(
        "Привет! Я бот-гид 🏛\n\nНапиши /places"
    )
```

### 6.2. Навигация по меню

```
def main_menu():
    keyboard = [
        [InlineKeyboardButton("Красная площадь ➡️", callback_data="red_square")],
        [InlineKeyboardButton("Арбат ➡️", callback_data="arbat")],
        [InlineKeyboardButton("Кремль ➡️", callback_data="kremlin")],
        [InlineKeyboardButton("Москва-Сити ➡️", callback_data="moscow_city")],
```

## 7. Возможные улучшения (планы на будущее)

В рамках дальнейшего развития проекта я планирую:

1. **Интерактивная карта достопримечательностей** - Добавить карту Москвы, где пользователь сможет видеть расположение всех объектов и переходить к ним прямо из бота.
3. **Режим “Экскурсия”** - Пошаговый маршрут по достопримечательностям с кнопками “Следующая” и “Предыдущая”, как мини-тур по городу.
4. **AI-экскурсовод** - Добавить чат-режим, где бот отвечает на вопросы о местах в стиле гида (например: “что это за место?”, “когда построено?”).
5. **Статистика и популярные места** - Собирать данные о том, какие достопримечательности чаще открывают, и показывать “топ популярных мест”.
